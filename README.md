# CT2Utils

Tools for handling `.CT2` tape images of the TK2000 computer (Microdigital).

**About this repository**

CT2Utils was created by **Fabio Belavenuto** (FBLabs), originally published at
https://github.com/fbelavenuto/ct2utils (first exported from code.google.com/p/ct2utils). This
repository preserves his full history, including the `wiki` branch, so his work stays available.
It is licensed under the GNU General Public License v2, as he published it (see `LICENSE`).

Fabio passed away in 2024
([news, in Portuguese](https://oldplayers.com.br/wp/2024/10/11/faleceu-fabio-belavenuto/)).
He also wrote the TK2000 emulator, preserved at https://github.com/ramurti/emulador-tk2000.

*In memory of Fabio Belavenuto.*

The original documentation is in `README` (English and Portuguese) and `doc/`.
